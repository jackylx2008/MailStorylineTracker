# 2026-09-28 审核、筛选界面与安全取消更新

## 邮件人工审核

- 审核页顶部可按 From/To/Cc 地址以及主题、完整正文、附件名关键词分别筛选；同一输入框用英文逗号分隔多个值。
- 从 GUI 打开的审核页提供“删除条目”和“撤销上次删除”。删除是项目级排除，不会删除本地 `.eml`、附件或服务器邮件。
- 排除记录写入本地 `data/state/review_exclusions.json`（实际位置随 `MAIL_DATA_DIR` 配置变化）。重新生成审核页、目标附件故事线及 AI 总结时，不再纳入这些邮件。
- 旧版审核页留在原浏览器 `localStorage` 的删除记录，需要重启 GUI 并从同一浏览器再次打开审核页，才会导入项目级状态。确认页面显示已同步的排除数量。
- 常规预览、增量下载和目标扫描在已知账号、文件夹、`UIDVALIDITY + UID` 来源命中排除记录时，跳过 FETCH；修改筛选条件也不会重新下载。若同一邮件以新 UID 出现，可能需要一次预览来根据 Message-ID 识别，但不会再次完整下载。
- 为发现其他新邮件，服务器端文件夹与 UID SEARCH 仍会执行；审核排除不等于删除服务器邮件。

## GUI 布局

- 原“目标附件链路”独立选项卡合并到“邮箱连接与筛选”页下半部，GUI 现在有四个选项卡。
- 三个 `target_*.env` 的内容载入可编辑的多行输入框；常规地址和关键词配置为空时，以目标联系人、目标关键词填充初始值。
- “应用目标条件到常规筛选”将目标联系人加入 From、To/Cc，目标关键词加入主题/正文关键词。附件事项的 AI 模糊匹配仍由专项扫描执行。
- 专项扫描使用同页的日期和每文件夹候选数，继续枚举账号下全部可选择文件夹；普通预览/下载仍遵循上方文件夹输入。

## 主动取消

- GUI 点击“取消任务”后，当前网络操作结束即安全停止，状态为“已取消”，不再记录为邮件处理 ERROR，也不输出取消异常的 traceback。
- 常规下载和目标扫描返回未完成摘要；已经完整落盘的邮件与增量检查点保留，下次运行继续。
- 真正的网络错误仍按失败处理。自动化测试中的模拟断线 traceback 不属于主动取消路径。
