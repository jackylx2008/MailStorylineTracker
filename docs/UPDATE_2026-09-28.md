# 2026-09-28 项目更新

## 完整邮件与附件归档

- 专项目标扫描在候选初筛命中后保存完整 `.eml` 和全部附件，不再只保留部分邮件内容。
- 已有部分记录会在后续专项扫描时自动升级；只有文件成功落盘后才写入完成状态。
- 新增 `download_priority_mail.py`，为“声学”全文件夹、“已发送”全文件夹和 `target_email.env` 地址全文件夹检索提供独立断点队列。
- 优先队列不使用普通配置中的日期下限，适用于完整历史追溯；`--batch` 支持 1 至 50，默认 5。
- 无关键词完整归档对每封新邮件只执行一次完整 FETCH，省去“部分预览 + 完整下载”的重复读取。
- 不同队列遇到相同账号、文件夹、`UIDVALIDITY + UID` 时复用已经存在的完整本地记录，不重复下载邮件或附件。

## 本地目标重判

- 新增 `python mail_storyline.py target-local-classify`。
- 该命令不连接 IMAP、不消耗 126 下载流量，只扫描本地完整归档。
- 结合当前 `target_email.env`、`target_keyword.env`、`target_file.env` 和本地 AI 附件名模糊匹配，更新匹配原因、事项归属和 HTML/JSON 报告。
- 本地 AI 仍只接收附件文件名和目标事项名称，不读取附件正文。

## 持久化与持续运行

- 邮件记录增加完整/部分状态识别，可查询并复用同源完整记录。
- 每次成功处理一封邮件后保存断点，网络中断或进程退出后可继续运行。
- 针对 CloudStation、OneDrive 等同步程序短暂锁定状态文件的情况，原子替换增加有限次数指数退避重试。
- `target-scan` 支持 `--folders`，可在需要时只扫描明确指定的文件夹。
