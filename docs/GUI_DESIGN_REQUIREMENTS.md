# GUI 窗口设计要求

本文档规定 Mail Storyline Tracker 桌面 GUI 的结构、交互行为和验收标准。

## 1. 总体结构

使用单一 Tkinter/ttk 主窗口，从上到下固定排列：

```text
功能选项卡
当前选项卡参数与操作
共享实时日志
总体进度、状态、当前对象、耗时和取消按钮
```

功能选项卡位于标题栏后的第一个主要区域。切换选项卡时，共享日志、进度和状态不得移动或清空。

## 2. 功能选项卡

第一阶段包含：

- 邮箱连接与筛选：文件夹、From、To/Cc、关键词、日期范围和 any/all 模式。
- 下载与归档：增量下载、本地数据路径和邮件审核页。
- 目标附件链路：读取三个本地目标文件，扫描全部邮箱文件夹并生成思维导图式 HTML。
- “目标附件链路”页将 `target_email.env`、`target_keyword.env`、`target_file.env` 分别显示为可编辑的多行输入框，每行一个值；文件内容是启动默认值，界面修改仅影响本次运行，并支持从文件重新载入。
- AI 梳理与时间线：检查现有 AI 服务、生成事项时间线及打开 HTML。
- 全局配置：显示配置、凭据文件、数据、输出和日志位置；不得展示密码或 API Key。

GUI 中的筛选修改仅影响当前任务，不写回 `config.yaml` 或 `.env`。

## 3. 邮件筛选交互

- 文件夹、发件人、收件人/Cc 和关键词支持逗号分隔的多个值。
- 提供“每文件夹最多候选数”，首次运行建议为 50，避免一次读取范围过大。
- 日期必须使用 `YYYY-MM-DD`；结束日期遵循 IMAP `BEFORE` 的不含当日语义。
- `any` 表示任一已配置筛选组命中；`all` 表示所有已配置筛选组都命中。
- “检查连接”验证登录并读取文件夹，但不下载邮件。
- “列出文件夹”用于确认服务器实际名称，特别是中文文件夹。
- “筛选预览”允许获取邮件并在内存中判断，但不写入原始邮件、附件或增量状态。
- 预览先使用 IMAP 日期、地址和主题条件筛选，再读取候选邮件前 16 KB 检查正文；不下载完整邮件或附件。收到 126 `FETCH volume limit exceed` 后立即停止，不继续对后续 UID 重复请求。
- 检测到流量超限后持久化 24 小时本地冷却状态；冷却期内不再发出 FETCH。默认单次 FETCH 间隔 1.5 秒，每 10 次暂停 20 秒。上述节流数值是保守项目默认值；网易官方仅公开建议超限后间隔 24 小时再试，未公布具体请求频率阈值。
- 除“每文件夹最多候选数”外，后台还以 `MAIL_MAX_MESSAGES_PER_RUN=50` 限制单次运行的全文件夹总量；达到上限或连接中断时保存断点并安全停止。
- “开始增量下载”只保存新邮件或筛选配置改变后需要重新判断的邮件。

## 4. 日志、后台任务和取消

- 所有 IMAP、文件读写和 AI 请求必须在后台线程执行。
- 后台线程不得直接操作 Tk 控件，只能通过线程安全队列回到主线程更新。
- 同一时间只允许运行一个任务；运行期间禁用全部启动按钮。
- 取消采用安全边界：当前网络请求结束后，在处理下一封邮件前退出，不强制中断正在写入的文件。
- 日志区最多保留约 3000 行，清空界面日志不得删除磁盘日志。
- 失败同时更新日志、状态栏并显示简短中文对话框；不得显示邮箱密码或 API Key。

## 5. 状态栏

底部固定显示：

- 总体进度条；
- 就绪、运行、正在取消、完成、失败或已取消；
- 当前文件夹和 UID 或当前处理阶段；
- `HH:MM:SS` 实际耗时；
- 取消任务按钮。

## 6. HTML 查看

- 邮件审核页和事项时间线均为本地 UTF-8 HTML。
- 页面提供客户端搜索，不依赖外部 CDN、脚本或网络资源。
- 邮件审核页显示时间、发件人、收件人、主题、命中原因、附件和来源路径。
- 时间线页显示事项、参与人、状态、已完成事项、待办、责任人、截止日期、风险、事件顺序和原始记录 ID。
- AI 生成内容必须保留来源记录 ID；无法从邮件确认的信息显示“待确认”。
- 目标附件链路页面以一个根节点连接多个独立目标事项；事项内部按时间排列邮件事件，支持搜索以及全部展开/折叠。

## 7. 跨平台与验收

- 使用 Tkinter/ttk 原生控件和平台字体回退。
- 路径使用 `pathlib.Path`，不在 GUI 中硬编码盘符或用户名。
- Windows、macOS 和 Linux 保持相同的信息层级和控件顺序。
- 窗口最小尺寸必须避免区域重叠；日志区和参数区随窗口缩放，状态栏始终可见。
- 隐藏窗口构建测试不得长期驻留或要求人工点击。
